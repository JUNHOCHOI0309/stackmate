# MVP 범위

## 목표

물리 쌓기와 체스 전환의 결합이 재미있는지 빠르게 검증한다. 첫 MVP는 웹에서 실행되는 로컬 2인 프로토타입이다.

## MVP 포함

- 2D 측면 시점의 체스말 5종과 받침대
- 로컬 2인, 플레이어별 독립 랜덤 기물 순서
- 좌우 이동, 회전, 낙하
- 물리 안정화와 낙하 판정
- 생존 기물 계산
- 킹 고정, 폰 중앙 배치, 특수 기물 순서 배치
- 체스판 자동 전환
- 기본 체스 이동, 체크, 체크메이트, 캐슬링

## MVP 제외

- 회원가입과 전적
- 랭크, 친구, 관전, 리플레이
- 온라인 대전과 재접속
- AI, 채팅, 시즌
- 스킨, 고급 전환 연출, 모바일 최적화
- 앙파상, 폰 승격, 반복·50수 무승부는 후속 단계 검토

## 완료 기준

두 플레이어가 모든 쌓기·낙하 시나리오를 수행할 수 있고, 생존 기물로 유효한 체스판을 생성해 체크메이트까지 한 경기를 완주할 수 있어야 한다.
