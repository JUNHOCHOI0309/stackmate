# UI/UX 명세

## 로비

- 빠른 매칭, 친구 대전
- 전적, 설정
- 연결 상태와 준비 상태

## 쌓기 화면

- 현재 플레이어와 색상
- 현재 조작 중인 기물
- 턴 제한 시간과 남은 기물 수
- 이동·회전·낙하 입력 안내 또는 모바일 버튼
- 받침대와 낙하 기준선
- 상대 연결 상태

다음 기물 공개 여부는 [오픈 이슈](15_OPEN_ISSUES.md)로 남긴다.

## 체스 화면

- 8×8 체스판과 초기 배치 연출
- 선택된 기물 및 이동 가능한 칸
- 양쪽 체스 타이머
- 잡힌 기물, 체크 상태, 현재 차례
- 기권과 무승부 제안

## 결과 화면

- 승자 또는 무승부 사유
- 쌓기 단계 생존 기물 요약
- 체스 기보
- 재대결, 로비 이동

## 모바일 입력

쌓기 화면은 좌우 드래그로 이동하고, 화면 버튼으로 좌·우 회전과 낙하를 수행한다. 체스 화면은 기물 터치 후 목적지를 터치한다. 두 손가락 회전보다 화면 버튼이 일관되고 오작동이 적다.
