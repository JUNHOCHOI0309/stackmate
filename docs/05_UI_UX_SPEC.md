# UI/UX 명세

## 로비

- 빠른 매칭, 친구 대전
- 전적, 설정
- 연결 상태와 준비 상태

## 쌓기 화면

- 현재 플레이어와 색상
- 현재 조작 중인 기물
- 화면 중앙의 10초 턴 타이머와 플레이어별 남은 기물 수
- 이동·회전·낙하 입력 안내 또는 모바일 버튼
- 받침대와 낙하 기준선
- 상대 연결 상태

다음 기물 공개 여부는 [오픈 이슈](15_OPEN_ISSUES.md)로 남긴다.

## 체스 화면

- 8×8 체스판과 초기 배치 연출
- 선택된 기물 및 이동 가능한 칸
- 양쪽 체스 타이머
- 잡힌 기물, 체크 상태, 현재 차례
- 기권과 무승부 제안

## 쌓기 결과·체스 전환

- 쌓기 단계 승자와 낙하를 유발한 플레이어 표시
- 승자의 백·흑 선택 UI
- 체스 전환 전 양쪽 시작 시간과 승자 `+30초` 보너스 표시

## 결과 화면

- 승자 또는 무승부 사유
- 쌓기 단계 생존 기물 요약
- 체스 기보
- 재대결, 로비 이동

## 스킨·코스메틱

- 로비 또는 설정에서 쌓기·체스 단계의 공통 스킨을 장착하고 미리보기
- 스킨의 이름, 희귀도, 획득 경로, 장착 상태 표시
- 상대 스킨을 숨기거나 단순화해 표시하는 접근성·경쟁 모드 옵션
- 팀 색상, 선택, 체크, 이동 가능 칸은 스킨과 무관하게 명확히 표시

스킨의 표현·BM·기술 원칙은 [스킨·코스메틱 시스템](16_SKIN_SYSTEM.md)을 따른다.

## 모바일 입력

쌓기 화면은 좌우 드래그로 이동하고, 화면 버튼으로 좌·우 회전과 낙하를 수행한다. 체스 화면은 기물 터치 후 목적지를 터치한다. 두 손가락 회전보다 화면 버튼이 일관되고 오작동이 적다.
