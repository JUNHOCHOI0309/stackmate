# 테스트 계획

## 물리 테스트

- 모든 기물이 정상적으로 생성·낙하·회전하는가
- 기물이 바닥 또는 다른 기물을 통과하지 않는가
- 과도한 회전·진동이 없는가
- 안정화 상태가 일관되게 판정되는가
- 기물 중심점 기준 낙하 판정이 정확한가
- 첫 낙하 후 유예 시간 동안 생존 분류가 올바른가
- 10초가 지나면 현재 위치에서 자동 낙하하고 다음 턴 판정으로 넘어가는가
- 상대 기물이 먼저 낙하하면 조작 플레이어가 쌓기 승자가 되는가
- 같은 물리 프레임의 동반 낙하는 조작 플레이어 패배로 처리되는가
- 전 기물 30개가 안정화되면 쌓기 무승부로 처리되는가

## 체스 테스트

- 쌓기 단계 승자가 백·흑을 선택할 수 있는가
- 쌓기 단계 승자만 체스 시작 시간에 30초를 추가로 받는가
- 쌓기 단계 무승부에서는 진영이 무작위로 정해지고 시간 보너스가 없는가
- 생존 폰 수별 파일 배치가 올바른가
- 특수 기물의 성공 순서별 배치가 올바른가
- 킹이 항상 고정 위치에 놓이는가
- 초기 배치가 체크 상태가 아닐 때만 시작하는가
- 캐슬링 권한이 올바르게 생성·소멸하는가
- 앙파상, 승격, 체크메이트, 스테일메이트가 chess.js 상태와 일치하는가

## 온라인 테스트

- 양쪽 클라이언트의 권위 상태가 일치하는가
- 턴 중복과 상대 턴 입력이 차단되는가
- 잘못된 좌표·회전·기물 ID 요청이 거부되는가
- 재접속 후 턴·물리·타이머 상태가 복구되는가
- 지연·패킷 재전송 상황에서도 서버 결과가 유지되는가
