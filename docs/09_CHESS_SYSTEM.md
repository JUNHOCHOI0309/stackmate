# 체스 시스템

## 초기 보드 생성

쌓기 종료 후 생존 기물로 초기 보드를 생성한다. 탑에서의 위치·높이·회전은 반영하지 않는다.

### 킹

- 백 킹: `e1`
- 흑 킹: `e8`

### 폰

폰은 생존 개수만큼 중앙 우선 순서로 배치한다.

```text
d → e → c → f → b → g → a → h
```

백은 2랭크, 흑은 7랭크를 사용한다.

### 특수 기물

퀸·룩·비숍·나이트는 성공적으로 쌓인 시간 순서대로 배치한다.

```text
백: a → b → c → d → f → g → h
흑: h → g → f → d → c → b → a
```

백은 1랭크에서 `a`부터, 흑은 8랭크에서 `h`부터 배치한다. 이는 보드를 180도 회전했을 때 양측의 특수 기물 위치가 대응하도록 하며, `e` 파일은 킹에게 고정 배정한다.

## 초기 상태 검증

자동 배치 후 양쪽 킹의 체크 상태를 검사한다. 초기 체크가 생기면 공격 기물을 같은 진영의 가까운 유효한 빈 칸으로 조정한다. 이 검증을 통과한 보드로 FEN을 생성한다.

## chess.js 적용 범위

- 합법 수 판정 및 기물 이동
- 체크, 체크메이트, 스테일메이트
- 앙파상과 폰 승격
- 3회 동형 반복, 50수 규칙
- FEN·PGN 생성과 갱신

## 캐슬링

체스 시작 시 `a` 또는 `h` 파일의 시작 칸에 배치된 룩에 해당 방향의 권한을 부여한다. 이후 일반 캐슬링 조건을 적용한다.

- 킹과 대상 룩이 움직인 적이 없어야 한다.
- 두 기물 사이가 비어 있어야 한다.
- 킹이 체크 상태가 아니고 경유·도착 칸이 공격받지 않아야 한다.

## 체스 타이머와 결과

권장 시간제는 플레이어당 5분 + 매 수 2초이다. 쌓기 단계 승자는 백·흑을 선택하고 자신의 시작 시간에 30초를 추가해 `5분 30초 + 매 수 2초`로 시작한다. 상대는 `5분 + 매 수 2초`로 시작한다. 쌓기 단계가 무승부로 끝나면 양쪽 모두 기본 시간으로 시작한다.

승리 조건은 체크메이트, 상대 시간 초과, 기권이며, 무승부 조건은 스테일메이트·반복·50수 규칙·합의·메이트 불가능이다.
