# STACKMATE

## 한 줄 소개

체스말을 번갈아 쌓고, 기물이 떨어지는 순간 살아남은 체스말만으로 체스를 진행하는 1대1 물리 전략 게임.

## 기본 정보

| 항목 | 내용 |
| --- | --- |
| 장르 | 물리 쌓기 + 변형 체스 전략 |
| 플랫폼 | 웹 |
| 플레이 인원 | 1대1 |
| 게임 시점 | 2D 측면 쌓기 화면 + 2D 체스판 |
| 예상 플레이 시간 | 약 10~20분 |

## 핵심 콘셉트

경기는 `체스말 쌓기`와 `체스 대전`의 두 단계로 진행된다. 두 플레이어가 같은 탑에 체스말을 번갈아 쌓고, 하나라도 낙하하면 쌓기 단계를 멈춘다. 이후 살아남은 기물만으로 일반 체스를 진행해 최종 승패를 결정한다.

```text
체스말 쌓기 → 생존 기물 판정 → 체스판 자동 배치 → 체스 대전
```

## 핵심 차별점

일반적인 물리 쌓기 게임에서 낙하는 경기의 끝이다. STACKMATE에서는 낙하가 두 번째 전략 게임의 시작이다. 쌓기 실력은 병력 확보에, 체스 실력은 최종 역전에 영향을 준다.

## 목표 이용자

- 조작은 쉽지만 반복해서 숙련할 수 있는 대전 게임을 원하는 이용자
- 체스의 전략성과 파티 게임의 긴장감을 함께 즐기고 싶은 이용자
- 짧은 온라인 1대1 또는 로컬 2인 게임을 선호하는 이용자
