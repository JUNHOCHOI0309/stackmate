# 물리 명세

## 기본 원칙

STACKMATE는 2D 측면 시점의 물리 쌓기 게임이다. 게임성은 체스 기물의 가치가 아니라 형태와 무게중심의 차이에서 만들어야 한다. 따라서 초기 버전에서는 기물별 질량 차이를 크게 두지 않는다.

```ts
const defaultPhysics = {
  friction: 0.7,
  restitution: 0.05,
  linearDamping: 0.2,
  angularDamping: 0.4,
};
```

중력과 기물별 실제 크기·질량은 프로토타입 플레이 테스트로 확정한다.

## 콜라이더

이미지 외곽선을 그대로 쓰지 않고, 작은 돌출부로 인한 끼임을 피하기 위해 단순 콜라이더를 조합한다.

| 기물 | 콜라이더 | 상대 크기 | 물리 특징 |
| --- | --- | --- | --- |
| 폰 | 원형 + 사각형 | 소형 | 틈을 채우기 쉬움 |
| 룩 | 복합 사각형 | 중형 | 넓은 접촉면으로 받침에 유리 |
| 나이트 | 볼록 다각형 + 사각형 | 중형 | 비대칭 형태 |
| 비숍 | 캡슐 + 사각형 | 중형 | 세로 배치가 불안정 |
| 퀸 | 볼록 다각형 + 사각형 | 대형 | 큰 상단으로 배치 난도 높음 |

백과 흑은 같은 측면 실루엣과 콜라이더를 사용하고 색상만 다르게 해 물리적 공정성을 유지한다.

## 안정화와 낙하

- 착지 후 약 2초 동안 선형·각속도를 확인한다.
- 속도가 각각의 임계값 이하이고 낙하 기준선 위에 있으면 안정화 성공이다.
- 어느 기물의 중심점이 낙하 기준선을 통과하면 낙하가 발생한다.
- 첫 낙하 뒤 약 1초 유예를 적용한 뒤 물리 시뮬레이션을 정지한다.
- 정지 시점에 기준선 위에 남은 기물을 생존으로 확정한다.

임계 속도, 중력, 받침대 크기, 낙하 기준선 높이는 수치 테스트를 통해 확정한다.
