# Git 작업 규칙

## 커밋 메시지

커밋 메시지는 **한글로 작성**한다. 변경 목적을 짧고 명확하게 나타내며, 하나의 커밋에는 하나의 논리적인 변경만 담는다.

권장 형식:

```text
<유형>: <변경 요약>
```

예시:

```text
feat: 비공개 방 초대 링크 보안 강화
fix: 메인 복귀 시 방 세션 정리
docs: Render 배포 절차 문서화
refactor: WebSocket 메시지 처리 분리
test: 방 참가 요청 제한 테스트 추가
```

## 커밋 전 확인

코드 변경이 포함된 경우 다음을 확인한다.

```powershell
npm run build
git diff --check
git status --short
```

## 제외할 파일

- `.env`와 비밀값
- 빌드 결과물과 의존성 폴더
- 개인 개발 도구가 만든 추적 대상이 아닌 파일

저장소에 포함하지 않아야 할 파일은 `.gitignore`에 추가한다.
