# 게임 규칙

## 전체 진행

```text
색상 결정 → 쌓기 단계 → 낙하 또는 전 기물 배치
→ 생존 기물 판정 → 체스판 자동 배치 → 체스 단계 → 결과
```

백은 쌓기 단계와 체스 단계 모두 먼저 행동한다. 재대결에서는 색상을 교체한다.

## 기물 구성

각 플레이어는 킹 1개, 퀸 1개, 룩 2개, 비숍 2개, 나이트 2개, 폰 8개를 갖는다. 킹을 제외한 15개 기물만 쌓기 단계에 참여한다. 킹은 체스 단계 시작 시 백 `e1`, 흑 `e8`에 고정 배치한다.

킹을 제외하면 킹 낙하 예외가 필요 없고, 정상적인 체크·체크메이트 규칙을 유지할 수 있다.

## 쌓기 단계

각 플레이어의 15개 기물 순서는 서로 독립적으로 무작위로 결정된다. 현재 플레이어는 등장한 기물을 좌우로 이동하고 회전한 뒤 떨어뜨린다.

| 입력 | 기능 |
| --- | --- |
| `A` / `D` 또는 방향키 | 좌우 이동 |
| `Q` / `E` | 좌우 회전 |
| `Space` | 낙하 |

- 턴 제한 시간: 10초 권장
- 시간 초과 시: 현재 위치에서 자동 낙하
- 안정화 시간: 착지 후 약 2초
- 성공 조건: 이동·회전 속도가 기준 이하이고 낙하 판정 영역에 있지 않음

## 쌓기 종료와 생존 판정

현재 플레이어의 행동으로 어느 기물이든 경기장 밖으로 떨어지면 쌓기 단계를 종료한다. 새 기물뿐 아니라 기존 탑의 자신의 기물 또는 상대 기물이 떨어져도 해당한다.

```text
기물 중심점이 낙하 기준선 통과 → 약 1초 유예 → 물리 정지 → 생존·낙하 분류
```

종료 시 낙하 기준선 위에 남아 있고 물리 정지 시 생존 상태인 기물만 체스 단계에 사용한다. 떨어진 기물과 아직 등장하지 않은 기물은 제외한다. 양쪽이 15개 기물을 모두 안정적으로 쌓으면 양쪽 모두 완전한 병력으로 체스를 시작한다.

## 체스판 배치

탑의 높이, 가로 위치, 회전, 쌓인 형태는 체스판에 반영하지 않는다. 생존 기물의 종류·개수와 특수 기물의 성공 배치 순서만 반영한다.

### 폰

생존한 폰은 중앙부터 바깥쪽 순서로 배치한다.

```text
d → e → c → f → b → g → a → h
```

백 폰은 2랭크, 흑 폰은 7랭크에 둔다. 예를 들어 3개가 생존하면 `c`, `d`, `e` 파일에 배치한다.

### 특수 기물

생존한 퀸·룩·비숍·나이트는 성공적으로 쌓인 시간 순서대로 배치한다.

```text
백: a1 → b1 → c1 → d1 → f1 → g1 → h1
흑: a8 → b8 → c8 → d8 → f8 → g8 → h8
```

`e` 파일은 킹을 위해 비워 둔다. 초기 배치 뒤 양쪽 킹의 체크 상태를 검사하고, 체크가 생기면 공격 기물을 같은 진영의 가까운 유효한 빈 칸으로 조정한다.

## 체스 규칙과 결과

체스 단계는 백 선공의 일반 체스 규칙을 따른다. 기물 이동, 체크, 체크메이트, 스테일메이트, 앙파상, 폰 승격, 3회 동형 반복, 50수 규칙, 시간 초과, 기권을 적용한다.

캐슬링은 킹이 `e` 파일 시작 칸에 있고, 대상 룩이 `a` 또는 `h` 파일 시작 칸에 있으며, 일반 캐슬링 조건을 충족할 때만 허용한다.

| 결과 | 조건 |
| --- | --- |
| 승리 | 체크메이트, 상대 시간 초과, 상대 기권 |
| 무승부 | 스테일메이트, 3회 동형 반복, 50수 규칙, 합의, 메이트 불가능 |

권장 체스 시간제는 플레이어당 5분 + 매 수 2초 추가다.
