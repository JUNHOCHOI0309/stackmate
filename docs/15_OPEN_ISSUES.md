# 오픈 이슈

아래 항목은 확정 시 이 문서에서 제거하고 관련 명세에 반영한다.

- 다음 기물을 미리 보여줄 것인가
- 랜덤 기물 편차를 어느 범위까지 허용할 것인가
- 쌓기 턴 제한은 정확히 몇 초인가
- 회전은 자유 회전인가, 15도 단위인가
- 기존 기물이 하나라도 떨어지면 항상 종료하는가
- 첫 낙하 뒤 물리를 정확히 몇 초 더 진행하는가
- 양쪽이 모든 기물을 쌓으면 즉시 체스로 전환하는가
- 쌓기 선공과 체스 백을 항상 동일하게 할 것인가
- 체스 시간제와 무승부 처리 정책은 무엇인가
- 기물별 물리 크기와 체스 가치 간 밸런스를 어떻게 검증할 것인가
- `a`·`h` 파일 룩의 캐슬링 권한을 어떤 내부 데이터로 표시할 것인가
- 연결 끊김, 장기 이탈, 서버 장애를 어떻게 처리할 것인가
- 서버 물리의 결정론과 클라이언트 보정 방식을 어떻게 설계할 것인가
