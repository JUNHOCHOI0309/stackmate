# 네트워크 명세

## 메시지

| 메시지 | 방향 | 목적 |
| --- | --- | --- |
| `JOIN_MATCH` | 클라이언트 → 서버 | 매치 참가 |
| `PLAYER_READY` | 클라이언트 → 서버 | 준비 완료 |
| `DROP_PIECE` | 클라이언트 → 서버 | 낙하 요청 |
| `PHYSICS_SNAPSHOT` | 서버 → 클라이언트 | 권위 있는 물리 상태 배포 |
| `TURN_SETTLED` | 서버 → 클라이언트 | 안정화와 턴 종료 통지 |
| `STACK_FINISHED` | 서버 → 클라이언트 | 생존 기물 확정 |
| `CHESS_STARTED` | 서버 → 클라이언트 | 초기 FEN과 체스 시작 통지 |
| `CHESS_MOVE` | 양방향 | 체스 수 요청·결과 배포 |
| `OFFER_DRAW` / `ACCEPT_DRAW` | 양방향 | 무승부 제안·수락 |
| `RESIGN` | 클라이언트 → 서버 | 기권 요청 |
| `MATCH_FINISHED` | 서버 → 클라이언트 | 결과 확정 |
| `RECONNECT` | 클라이언트 → 서버 | 재접속과 상태 복구 |

```json
{
  "type": "DROP_PIECE",
  "pieceId": "white-knight-1",
  "x": 2.4,
  "rotation": 1.57,
  "turnNumber": 6
}
```

## 검증과 예외 처리

- 서버는 현재 턴, 기물 소유, 좌표 범위, 회전 범위를 검증한다.
- 중복 요청과 상대 턴 조작은 거부한다.
- 체스 수는 서버의 chess.js 상태에서 합법성 검증 후 적용한다.
- 재접속 시 서버는 현재 상태와 남은 시간을 전달한다.
- 턴 중 장기 이탈, 서버 종료, 지연 기준과 패배 처리는 별도 정책으로 확정한다.
