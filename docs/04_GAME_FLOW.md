# 게임 흐름

## 사용자 여정

```text
웹사이트 접속 → 닉네임 또는 로그인 → 빠른 매칭 또는 친구 대전
→ 상대 연결 → 색상 결정 → 쌓기 단계 → 생존 기물 판정
→ 체스판 전환 → 체스 단계 → 결과 화면 → 재대결 또는 로비
```

## 게임 상태

| 상태 | 설명 |
| --- | --- |
| `WAITING` | 방 생성 또는 상대 대기 |
| `READY` | 양쪽 준비 완료 대기 |
| `STACKING` | 현재 플레이어가 기물을 조작하는 중 |
| `SETTLING` | 낙하 후 물리 안정화 확인 중 |
| `TRANSITION` | 생존 기물을 확정하고 체스판을 구성하는 중 |
| `CHESS` | 체스 수를 진행하는 중 |
| `FINISHED` | 승패·무승부를 확정한 상태 |

## 전환 원칙

쌓기 단계의 물리 상태는 서버가 확정한다. `TRANSITION`에서는 물리 시뮬레이션을 정지하고 생존 기물 목록과 초기 체스 상태를 생성한다. 체스 단계는 고정된 스프라이트와 체스 규칙 엔진만 사용하며 물리를 적용하지 않는다.
