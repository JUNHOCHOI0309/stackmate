# 레퍼런스 분석

## Animal Tower Battle에서 가져오는 요소

*Animal Tower Battle*은 두 플레이어가 서로 다른 모양의 물체를 번갈아 쌓는 물리 대전 게임이다. 핵심 조작은 위치 결정, 회전, 낙하이며, 기물의 접촉면·무게중심·탑의 흔들림이 결과를 만든다.

STACKMATE는 다음 요소를 참고한다.

- 번갈아 하나씩 배치하는 짧은 턴 구조
- 별도 설명 없이 위험을 읽을 수 있는 물리적 흔들림과 낙하
- 형태별로 달라지는 배치 난이도
- 경쟁하지만 하나의 탑을 함께 만드는 상호 의존성

## 그대로 사용하지 않는 요소

레퍼런스 게임은 물체를 먼저 떨어뜨린 플레이어가 즉시 패배한다. STACKMATE는 낙하를 쌓기 단계의 종료 조건으로만 사용하며, 생존 기물로 이어지는 체스 단계에서 최종 승패를 결정한다.

| 구분 | Animal Tower Battle | STACKMATE |
| --- | --- | --- |
| 쌓는 물체 | 동물 | 체스말 |
| 조작 | 위치·낙하 | 이동·회전·낙하 |
| 낙하 발생 | 즉시 패배 | 쌓기 단계 종료 |
| 이후 진행 | 경기 종료 | 생존 기물로 체스 시작 |
| 최종 승패 | 쌓기 결과 | 체스 결과 |

## 체스에서 가져오는 요소

- 8×8 체스판과 백 선공
- 기물별 기본 이동 규칙과 합법 수 판정
- 체크, 체크메이트, 스테일메이트
- 캐슬링, 앙파상, 폰 승격
- 시간제와 기권, 무승부 조건

일반 체스와 다른 점은 초기 병력과 백랭크 구성이다. STACKMATE는 쌓기 결과로 병력과 특수 기물의 위치를 결정한다.
