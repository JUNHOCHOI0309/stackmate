# 개발 로드맵

## Phase 1 — 로컬 물리 쌓기

Phaser와 Rapier 2D로 기물 생성, 이동, 회전, 낙하, 안정화, 낙하 판정을 구현한다.

## Phase 2 — 생존 기물과 체스 전환

생존 기물을 기록하고, 규칙에 따라 초기 보드·FEN을 생성하며, 전환 화면을 구현한다.

## Phase 3 — 체스 규칙 완성

chess.js를 연결해 합법 수, 체크메이트, 캐슬링을 구현하고 후속으로 앙파상·승격·무승부 규칙을 추가한다.

## Phase 4 — 온라인 1대1

Colyseus MatchRoom, 서버 권위 물리·체스 판정, 턴 타이머, 재접속을 구현한다.

## Phase 5 — 계정과 경쟁 기능

계정, 전적, PGN, 레이팅, 매칭을 추가한다.

## Phase 6 — 완성도 향상

전환 연출, SVG 필터·텍스처 기반 스킨, 모바일 최적화, 관전, 리플레이를 추가한다. 스킨은 물리와 규칙을 바꾸지 않는 코스메틱으로 제공한다.
