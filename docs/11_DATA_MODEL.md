# 데이터 모델

## 초기 테이블

```text
users
matches
stack_turns
stack_results
chess_games
ratings
```

## 주요 데이터

| 영역 | 저장 데이터 |
| --- | --- |
| 사용자 | 사용자 ID, 표시 이름, 생성일 |
| 경기 | 참가자, 백·흑, 시작·종료 시각, 종료 사유, 승패 |
| 쌓기 턴 | 플레이어별 랜덤 기물 순서, 기물 ID, 낙하 위치, 회전, 턴 번호 |
| 쌓기 결과 | 생존·낙하 기물, 종료 시점, 낙하 원인 |
| 체스 경기 | 초기 FEN, 최종 FEN, PGN, 시간제, 종료 사유 |
| 레이팅 | 사용자별 레이팅, 경기 전후 값 |

## 보존 원칙

경기 재현과 분쟁 확인을 위해 서버가 확정한 입력·물리 결과·체스 기보를 저장한다. 원본 물리 스냅샷 전체 저장 여부와 보존 기간은 서비스 규모에 맞춰 결정한다.
