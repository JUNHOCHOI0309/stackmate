# 스킨·코스메틱 시스템

## 목적

스킨은 기물의 외형만 바꾸는 코스메틱 콘텐츠이자, 향후 유료 판매·이벤트 보상·시즌 보상의 대상이다. 모든 스킨은 쌓기 단계와 체스 단계에 일관되게 적용한다.

게임 결과와 공정성에는 영향을 주지 않는다. 기물의 콜라이더, 질량, 마찰, 크기, 낙하 판정, 체스 기물 종류와 이동 규칙은 스킨과 독립적으로 고정한다.

## 적용 범위

| 영역 | 스킨 적용 방식 |
| --- | --- |
| 쌓기 단계 | 체스말의 측면 실루엣 위에 재질·색상·장식 레이어를 표현한다. |
| 체스 단계 | 같은 테마의 위에서 본 체스말과 체스판 팔레트를 적용한다. |
| UI | 장착 중인 테마 이름, 미리보기, 희귀도와 획득 경로를 표시한다. |

상대가 선택한 스킨도 표시하되, 팀 색상(백·흑), 현재 선택 상태, 체크 상태, 이동 가능 칸은 스킨 위에서도 명확히 구분되어야 한다.

## 에셋 구조

스킨은 기물별 완성 이미지를 개별로 보관하기보다 재사용 가능한 기본 SVG와 테마 데이터의 조합으로 구성한다.

```text
public/assets/skins/
├─ base/
│  ├─ stack/                 # 쌓기용 측면 실루엣 SVG
│  └─ chess/                 # 체스판용 상단 시점 SVG
└─ themes/
   └─ <theme-id>/
      ├─ skin.json           # 이름, 희귀도, 색상, 필터, 라이선스 정보
      ├─ texture.svg|png     # 선택적 반복 텍스처
      └─ preview.png
```

`skin.json`은 최소한 다음을 기록한다.

```ts
type SkinDefinition = {
  id: string;
  displayName: string;
  rarity: 'common' | 'rare' | 'epic' | 'legendary';
  palette: { light: string; dark: string; accent: string };
  texture?: string;
  svgFilter?: 'none' | 'metal' | 'marble' | 'wood' | 'neon';
  source: { author: string; license: string; url?: string };
};
```

## SVG 필터와 텍스처

기본 기물 SVG에는 재질을 칠할 수 있는 단일 실루엣 레이어와, 팀 색상·테두리·강조선을 위한 별도 레이어를 둔다. 테마는 SVG의 `mask` 또는 `clipPath`로 텍스처를 실루엣 내부에 제한하고, 다음 필터 조합으로 재질감을 만든다.

- 금속: `feTurbulence` + `feColorMatrix` + `feSpecularLighting`
- 대리석·나무: 반복 텍스처 + `feDisplacementMap` 또는 약한 노이즈
- 네온: `feGaussianBlur` + `feMerge`로 외곽 발광

필터는 매 프레임 브라우저 DOM에 적용하지 않는다. 스킨을 장착하거나 게임 씬을 로드할 때 SVG를 Phaser 텍스처로 래스터화·캐시하고, 플레이 중에는 일반 텍스처로 렌더링한다. 이 방식은 모바일 성능과 브라우저별 SVG 필터 차이를 줄인다.

애니메이션 필터나 셰이더 효과는 희귀 스킨의 선택·승리 연출처럼 짧고 제한된 상황에서만 사용한다. 쌓기 중인 모든 기물에 지속적인 실시간 필터를 적용하지 않는다.

## 공정성·접근성 기준

- 스킨은 콜라이더와 무관하게 동일한 기준 크기·앵커를 사용한다.
- 백·흑의 명도 대비, 선택 테두리, 체크 경고는 어떤 팔레트에서도 유지한다.
- 텍스처가 강해도 기물 종류를 알아볼 수 있는 실루엣을 보존한다.
- 경쟁 모드에는 기본 스킨 또는 상대 스킨을 단순화해 표시하는 옵션을 제공한다.
- 효과음, 번쩍임, 고대비·색각 보정 옵션은 별도로 끌 수 있어야 한다.

## BM과 제공 방식

스킨은 유료 판매, 시즌 패스, 이벤트 보상, 업적 보상으로 제공할 수 있다. 가격·희귀도·획득 여부는 계정 인벤토리 데이터이며, 매치 서버는 게임 시작 시 장착한 `skinId`만 상대에게 전달한다. 서버 판정 데이터와 스킨 데이터는 분리한다.

첫 MVP에서는 기본 스킨 한 세트만 제공한다. 스킨 상점·인벤토리·결제는 온라인 계정 기능 이후에 추가한다. 스킨을 도입하기 전에 기본 SVG와 텍스처의 저작권·상업 이용 가능 여부를 `skin.json`의 `source`에 기록한다.

## 검증 항목

- 모든 스킨에서 동일한 물리 콜라이더와 앵커가 사용되는가
- 백·흑·선택·체크 상태가 색각 보정 없이도 구분되는가
- SVG 필터가 적용된 텍스처가 데스크톱과 모바일에서 같은 모습으로 표시되는가
- 스킨 전환 뒤 이전 텍스처와 GPU 메모리가 해제되는가
- 상대가 보유하지 않은 스킨도 매치에서 안전하게 표시되는가
