# 체스 효과음 출처

- `chess-move.mp3`: Chess.com 기본 테마 `move-self.mp3`
  - https://images.chesscomfiles.com/chess-themes/sounds/_MP3_/default/move-self.mp3
- `chess-capture.mp3`: Chess.com 기본 테마 `capture.mp3`
  - https://images.chesscomfiles.com/chess-themes/sounds/_MP3_/default/capture.mp3

이 파일들은 프로젝트 사용자가 제공한 URL에서 내려받았다. 실제 서비스 배포 전에는 Chess.com의 이용 약관과 해당 음원의 재배포·상업적 사용 가능 여부를 확인해야 한다.

## 쌓기 효과음

- `droping_sound.m4a`: 프로젝트 사용자가 제공한 낙하 효과음
- `piece_crash_1.m4a`, `piece_crash_2.m4a`: 프로젝트 사용자가 제공한 기물·받침대 충돌 효과음
