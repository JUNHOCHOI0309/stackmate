# Chessnut SVG chess pieces

retrieved from the Lichess `lila` project:

- Source: https://github.com/lichess-org/lila/tree/master/public/piece/chessnut
- Original author: Alexis Luengas

The SVG files are retained as separate, unmodified assets.
